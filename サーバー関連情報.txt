【完全バックアップと復旧】
このフォルダの全ファイルを保管すれば、静的なゲーム画面・画像・スクリプトは再配置できる。ただしオンライン対戦とランキングの継続には上記の外部サービスも必要。
編集のたびに全ファイル入り ZIP を受け取り、スマホに保存。動作確認後に OneDrive 側のバックアップも更新する。古い正常版は必要な期間残す。
復旧時：ZIP を展開してスマホの Match3 フォルダ直下に index.html など全ファイルが揃うことを確認し、GitHub リポジトリに反映。GitHub Pages の公開を確認して、トップ・単独プレイ・オンライン対戦・ランキング・インストール版をそれぞれ試す。
Termux 側の既存手順：スマホの Download/ゲーム/モンパッチ/Match3/ に全ファイルを置き、Termux の ~/.bashrc にある upload3 の src が同じ「Match3」（大文字 M）を指していることを確認してから upload3 を実行する。upload3 はファイルの追加・更新をコピーするが、元フォルダから削除したファイルを Git 側から自動削除しない。整理・削除は対象を確認して別途行う。
Git の履歴だけを頼りにせず、動作確認済みの全ファイル ZIP を保管する。
